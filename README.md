# Enterprise Integration Hub

Vendor-neutral Enterprise Integration Architecture Workbench by **Niranjan Potter** — live at [https://niranjanpotter.dpdns.org/](https://niranjanpotter.dpdns.org/).

## Features (100% Offline, Zero Backend)
- **Integration Pattern Advisor & ADR Generator:** Choose interaction model, volume, delivery guarantees, ecosystem, and priority to generate the recommended architecture flow, cross-platform mapping (MuleSoft / AWS / Enterprise), anti-patterns, executive pitch, and a 1-click Markdown ADR.
- **Enterprise Reference Blueprints:** Interactive visual architectures for Salesforce ↔ SAP S/4HANA bidirectional sync, zero-downtime cloud migration, and Enterprise AI / MCP governance.
- **Daily Offline Integration Utilities:** Privacy-safe browser-only **JWT Claims Inspector**, **Unix / Quartz / Mule 4 Cron Builder**, and **JSON → OpenAPI 3.0 / RAML 1.0 Schema Generator**.
- **Full Screen Mode (`ESC` to exit)** & **Dark/Light Theme**, responsive across Mobile & Desktop.

## Deployment
Configured for 1-click static deployment on **Cloudflare Workers Static Assets** via `wrangler.jsonc` (`npx wrangler deploy`).
