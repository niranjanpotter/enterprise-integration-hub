When to Use Sync REST vs Async Queues

If a user is staring at a screen waiting for an answer, use synchronous API-led calls with parallel Scatter-Gather and caching (<350ms). If a downstream ERP takes 4 seconds or goes down every Sunday for maintenance, put a queue (Kafka, Anypoint MQ, SQS FIFO) in the middle and return HTTP 202 right away.
